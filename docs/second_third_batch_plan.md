## 公共行动接口约定
C 在 SevenLayerLoop 增加 configure_action(entity_id, target, step_size=1.0, policy="predictive", fixed_action="east")，target 可为目标实体 ID 或 3D 坐标；clear_action() 关闭。A 在 core.seven_layer_loop 增加 action="configure_action"/"clear_action"，转发参数。默认未配置时保持旧循环行为。
