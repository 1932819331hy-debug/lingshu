# 世界模型后续功能方案

完成世界过程功能后，再选择后续改进项目。
理论依据见 [世界模型理论总纲](https://github.com/FuRongJun-1999/lingshu/blob/cb3a6ea2dbd9771d685b2bf5c1fe398abe69e419/docs/theory/世界模型与语义时空图_完整理论整理与实现路线.md)。
原始证据文件保留不变。

## 后续项目

| 编号 | 功能 | 首个验证问题 |
|---|---|---|
| W1 | 误差诊断与定向修订 | 能否区分执行偏差和目标变化？ |
| W2 | 身份歧义与未知状态 | 同类实体交叉时，能否保留并列解释？ |
| W3 | 反事实试演 | 试演是否改变真实预测缓存？ |
| W4 | 条件化可靠性 | 工况分组能否降低留出 Brier 分数？ |
| W5 | 动作条件学习 | 动作标签能否降低留出位置误差？ |
| W6 | 主动视角与采样时间 | 换视角能否减少达到指定精度的帧数？ |

## 选择依据

完成过程识别与迁移后，重新测量现有误差。
优先处理新读数证明的功能缺口。
复用世界过程记录、事件序列和组合体结果。
每次只新增解决选定问题的机制。

## 本轮范围

本轮不开发 W1 至 W6。
功能收益和参数阈值仍未验证。
维护者决定架构取舍和正式验收。
